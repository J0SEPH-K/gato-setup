# GATO

Download **GatoSetup.exe** from the latest release, run it, press Next until it finishes.

1. Releases (right side of this page) -> Latest -> `GatoSetup.exe`
2. Run it and accept the admin prompt.
3. Start the game first (windowed, 1024x768, 1280x960 or 1440x1080), then open GATO from the Desktop shortcut.

Hotkeys: F3 start, F4 stop, F10 toggle.
